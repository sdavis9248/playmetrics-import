Download Reports from Sports Affinity

Navigate to Sports Affinity

3
Download Prior Years (Optional — Recommended)

To capture returning players who may have sat out a season, you can include prior years' data. The import tool will merge them, deduplicate by player name + DOB, and keep the most recent contact information.

Why bother? A player who played in 2024 but skipped 2025 still has a valid birth certificate on file. If they come back for 2026, importing them means they won't have to re-upload their BC.

How to Download Prior Years

  1. Go back to the Player Lookup page on Sports Affinity
  2. Change the Season dropdown to the prior year (e.g., "2024-2025 MY2024")
  3. Keep all other filters the same
  4. Download both reports again (Player Detail | upload format + All Player Applications Detail)
  5. Save them with distinguishable names (e.g., playerUpload_2024.xlsx, Player_Photo_BC_Info_2024.xlsx)
  6. Repeat for additional years if desired (2023-2024 MY2023, etc.)
⚠️ Diminishing Returns After 3 Years Players from 3+ years ago are less likely to return, and their contact info is more likely outdated. Two years of history (current + prior year) is a good balance. Three years is the practical maximum.
4
Run the PlayMetrics Import Tool

The tool handles all data transformation automatically — phone formatting, ZIP code truncation, gender mapping, BC status determination, age filtering, and the file split.

Option A: GUI (Recommended)

Double-click PlayMetricsImport.exe (Windows) or run python3 playmetrics_import.py (Mac) to open the application window.

  1. Add your Player Upload files — drag and drop your playerUpload .xlsx files into the top drop zone, or click Add Files to browse. Add files from multiple seasons to merge them.
  2. Add your BC Info files — drag and drop your Player Photo BC .xlsx files into the bottom drop zone, or click Add Files to browse.
  3. Click ▶ Run Import
  4. Review the results in the output log
  5. Click Open Output Folder to see your CSV files

Option B: Command Line (Advanced)

For batch processing or automation, you can run the tool from a terminal with --dir to point at a folder. The tool auto-detects all matching files, merges multiple seasons, and runs with no prompts.

PlatformHow to Open a Terminal
WindowsOpen File Explorer → navigate to the folder → click the address bar → type cmd → press Enter
MacOpen Terminal (⌘+Space → type "Terminal") → type cd → drag the folder from Finder into the Terminal → press Enter
Windows: PlayMetricsImport.exe --dir C:\path\to\your\reports
Mac / Linux: python3 playmetrics_import.py --dir /path/to/your/reports

What the Tool Does

  1. Loads playerUpload*.xlsx and Player Photo BC*.xlsx files (handles underscores, spaces, and year suffixes like _2025)
  2. Merges multi-season data, deduplicating by player name + DOB, keeping most recent contact info
  3. Filters out aged-out players (born before Aug 1, 2007 for Fall 2026)
  4. Blanks team column — prior season teams don't exist in PM; teams built fresh after draft
  5. Determines BC status from BC upload and verification dates in the Player Photo BC Info report
  6. Validates phones — blanks invalid area codes (starting with 0 or 1) so PM won't reject the import
  7. Formats phones (XXX-XXX-XXXX), ZIPs (5 digits), DOBs (MM/DD/YYYY)
  8. Splits output into BC-verified and non-verified CSV files

What the Tool Produces

Four files in a playmetrics_output/ folder:

FileWhat It IsWhat To Do With It
playmetrics_bc_verified_YYYYMMDD.csvPlayers with BC on fileSend to PlayMetrics (success@playmetrics.com). They import and flag as verified.
playmetrics_non_verified_YYYYMMDD.csvPlayers without BCImport yourself in PM admin. These players will be prompted to upload during registration.
playmetrics_all_players_YYYYMMDD.csvCombined reference copyDo not import. For your records only.
import_log_YYYYMMDD.txtAudit logRecords which files were used, date/time, dedup stats, phone corrections, and output details. Keep for your records.

Review the Output CSVs

Open the CSV files in Excel or a text editor and spot-check before submitting.

6
Send BC-Verified File to PlayMetrics

PlayMetrics must import the BC-verified file on their end — you cannot do this yourself. They flag these players as BC-verified in the system so returning families skip the BC upload during registration.

  1. Email success@playmetrics.com
  2. Subject: "BC-Verified Player Import — [Your Region Name]"
  3. Attach the playmetrics_bc_verified_YYYYMMDD.csv file
  4. Mention that it's the standard Player Import CSV format with BC-verified players only
  5. Wait for confirmation that the import is complete before proceeding
✅ How BC Skip Works After Import Once PM imports these players as BC-verified, any player who registers and matches an imported record will automatically skip the BC upload question. New players (not in the import) will be prompted to upload their BC. The system handles both cases — no conditional question needed.
7
Import Non-Verified Players Yourself (Optional)

If the tool produced a non-verified CSV (players without a BC on file), you can import these yourself in PlayMetrics admin. If all your players had BC on file, the tool won't produce this file — skip this step.

  1. Log in to PlayMetrics admin
  2. Navigate to Players
  3. Click More Actions → Import Players
  4. Upload the playmetrics_non_verified_YYYYMMDD.csv file
  5. Map columns if prompted (they should auto-match since we used the standard template)
  6. Confirm the import
8
Verify Imported Data

After both imports are complete, spot-check records in PlayMetrics.
